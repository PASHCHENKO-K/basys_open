# BASYS

Приложение для Android, которое ведёт тренировки, замеры, сон и питание.
Записная книжка и калькулятор в одном: что вы делаете — оно записывает,
из записанного — считает.

Раздаётся узкому кругу. Это не продукт из магазина: у него нет поддержки,
нет обещаний по срокам и нет уверенности в том, чего он ещё не проверил.
Всё это ниже сказано прямо.

## Установка

**Проще всего — [страница установки](https://pashchenko-k.github.io/basys_open/).**
Она сама поймёт, с какого устройства вы пришли, и проведёт по шагам.

Вручную, если страница почему-то недоступна:

1. Откройте [последний релиз](../../releases/latest) и скачайте файл `.apk`.
2. Откройте скачанный файл. Android спросит разрешение ставить приложения
   из этого источника — его надо дать один раз.
3. Если Play Защита предупредит о неизвестном приложении — это ожидаемо:
   приложения не из магазина она не знает в лицо. Выберите «Всё равно установить».

Нужен Android 7.0 или новее. Файл занимает около 71 МБ.

### На iPhone и на компьютере

Файлом туда приложение не поставить: iOS запускает только подписанное Apple.
Поэтому есть **вторая дверь — то же самое приложение в браузере**:
[pashchenko-k.github.io/basys_open/app/](https://pashchenko-k.github.io/basys_open/app/).

⚠ **На iPhone его надо добавить на экран «Домой»** («Поделиться» → «На экран
„Домой“») и запускать оттуда. Открытое вкладкой Safari, оно работает **без
офлайна** — то есть в зале, где нет сети, не откроется.

⚠ **Журналы не связаны.** Приложение на телефоне и приложение в браузере ведут
свои записи, и свести их пока нечем. Выберите одно место.

⚠ **В браузере база не шифруется.** SQLCipher там не существует; данные лежат
в хранилище, приватном для этого адреса, и защищены код-паролем устройства.
Приложение говорит это прямо на экране «Система → Данные». И очистка данных
сайта уносит и базу, и копии разом — копию делайте наружу.

**Обновления.** Приложение само проверяет, вышла ли новая версия, и говорит
об этом на экране «Система → Данные». Скачивать надо оттуда же, отсюда —
установка поверх сохраняет все записи.

Кто не хочет следить руками — можно поставить
[Obtainium](https://github.com/ImranR98/Obtainium): он следит за релизами этого
репозитория и обновляет сам.

## Что с вашими данными

**Ничего никуда не отправляется.** Ни статистики, ни телеметрии, ни аккаунта.
Автор приложения не видит ваших записей и не может их увидеть: их просто нет
нигде, кроме вашего телефона. База на устройстве зашифрована, ключ лежит
в защищённом хранилище Android.

**Обратная сторона ровно та же.** Если телефон потерян, сломан или сброшен —
записи не восстанавливаются ниоткуда. Облачной копии нет намеренно: она
означала бы, что данные о здоровье лежат где-то ещё.

**Поэтому делайте копию.** «Система → Данные» → «Сделать копию». Копия
расшифрована и открывается любым просмотрщиком SQLite, а вернуть её в приложение
можно там же.

⚠ Пока вернуть можно только копию, сделанную на этом же телефоне: выбрать файл
из системы приложение ещё не умеет. То есть копия, отправленная наружу
и потерянная вместе с телефоном, обратно не заливается. Это чинится, но пока так.

## Чем это не является

**Это не медицинское изделие.** Оно не ставит диагнозов и не заменяет врача.
Решение поднимать вес принимаете вы. При боли, травме или ограничении
по здоровью — сначала врач.

**Правила не подписаны.** Приложение считает рекомендации по правилам, и из
девятнадцати правил не проверено по доказательной базе ни одно. Это не
скромность: приложение показывает состояние каждого правила внутри, в
«Система → Правила», и у каждого числа отдельно — «Откуда это число».

Иначе говоря: считает оно честно, но за то, что считает **правильно**, пока
никто не расписался.

## Обратная связь

Внутри есть тикеты — «Система → Тикеты». Замечание можно записать прямо
в зале, между подходами: приложение само подставит, на каком упражнении
и в какой фазе это было. Потом тикет можно отправить кнопкой «Поделиться» —
любым мессенджером, куда вам удобнее.

Ничего не отправляется само. Что уходит, вы видите целиком до отправки.

У кого есть учётная запись GitHub — можно писать в [Issues](../../issues).
